# Alexandr Abaskalov

Full-stack engineer in Almaty, Kazakhstan. Most of my work is TypeScript: Vue and Nuxt on the front end, Node.js behind it. I also ship mobile apps on Capacitor and Flutter, and lately a lot of what I build is LLM agents.

Here:

- [Scout](https://github.com/scout-dev-org/scout) - a self-hosted bug tracker. Testers file bugs from a widget on the page, and an AI coding agent works the queue. On a marketplace in testing it took 1,060 reports from April to September 2026, and 1,002 were fixed.
- [Perekluk](https://github.com/abaskalov/perekluk) - a small macOS app that fixes text typed in the wrong keyboard layout. A free alternative to Punto Switcher.
- [ha-rinnai-boiler](https://github.com/abaskalov/ha-rinnai-boiler) - Home Assistant integration for Rinnai gas boilers. It can run fully local: the boiler's Wi-Fi controller talks to a small server inside Home Assistant instead of the Rinnai cloud.
- [page-capturer](https://github.com/abaskalov/page-capturer) - a Playwright service that saves a rendered page as one HTML file you can open offline.
- [claude-code-skills](https://github.com/abaskalov/claude-code-skills) - skills from my own Claude Code setup.
